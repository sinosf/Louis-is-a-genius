# Louis is a genius 🔮🧠

Site web Gen Z pour célébrer le génie de Louis.

- `index.html` — page qui explique pourquoi Louis est un génie
- `ask.html` — la "boule magique" : formulaire pour laisser une question et des infos de contact, avec réponse envoyée par Louis ensuite
- `style.css` — style visuel (gradients, glassmorphism, vibe Gen Z)
- `script.js` — logique du formulaire (démo front-end)

## Activer GitHub Pages
Pour voir le site en ligne : Settings → Pages → Branch `main` → dossier `/ (root)`.

## Envoi réel des messages
Actuellement le formulaire ne fait que logger la demande côté navigateur (démo). Pour envoyer réellement un message à Louis à chaque soumission (email/SMS), il faudra brancher un service comme Formspree, EmailJS ou un petit backend (ex: Zapier + webhook).
